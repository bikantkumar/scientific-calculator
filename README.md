# 🔢 Advanced Scientific Calculator

A Python-based Advanced Scientific Calculator designed to perform a wide range of mathematical operations through a simple, menu-driven interface.

This project started as a Python mini-project with the goal of bringing multiple mathematical functions together in one place. Instead of switching between different tools for calculations, you can perform everything from basic arithmetic to complex mathematical operations using a single program.

## ✨ Features

The calculator supports the following operations:

| No. | Feature | Description |
|---|---|---|
| 1 | Basic Arithmetic | Addition, subtraction, multiplication, division and percentage |
| 2 | Powers & Roots | Square, cube, powers, square root and nth root |
| 3 | Logarithms | Log base 10, natural logarithm and exponential |
| 4 | Trigonometry | Sine, cosine, tangent and inverse trigonometric calculations |
| 5 | Hyperbolic Functions | Sinh, Cosh, Tanh and inverse hyperbolic functions |
| 6 | Factorial & Combinatorics | Factorial, permutations (nPr) and combinations (nCr) |
| 7 | Fractions | Fraction and decimal conversion |
| 8 | Statistics | Mean, median and standard deviations |
| 9 | Equation Solver | Solves mathematical equations and finds roots |
| 10 | Calculus | Differentiation and indefinite/definite integration |
| 11 | Complex Numbers | Arithmetic, magnitude, conjugate and polar form |
| 12 | Matrix Operations | Matrix addition, multiplication, determinant and inverse |
| 13 | Number System | Decimal, binary, octal and hexadecimal conversion |
| 14 | Prime Factorization | Finds the prime factors of an integer |
| 15 | Function Table | Generates values of a mathematical function |
| 16 | Angle Mode | Switch between Degree, Radian and Gradian modes |
| 17 | Answer Memory | Recall the current and previous calculation results |

## 🛠️ Technologies Used

- **Python 3** – Main programming language.
- **Math** – Mathematical and trigonometric operations.

Before running the project, make sure you have:

- Python 3.9 or later
- A code editor such as Visual Studio Code (optional)
- Internet connection for installing the required library

## 🚀 Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/your-username/your-repository-name.git
```

**2. Open the project folder**

```bash
cd your-repository-name
```

**3. Install the required dependency**

```bash
pip install sympy
```

**4. Run the calculator**

```bash
python calculator.py
```

## 💻 How to Use

1. Run the Python file.
2. A menu containing 17 mathematical options will appear.
3. Enter the number corresponding to the operation you want.
4. Provide the required input.
5. View the calculated result.
6. Continue performing calculations or select `0` to exit.
